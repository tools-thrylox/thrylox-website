# Investor Evidence Template

## Goal
Summarize the BOG paid playtest in a way that proves real demand, product clarity, and growth potential without overstating what the demo already validates.

## Player Value
N/A for players. This document converts raw test output into a stakeholder decision artifact.

## Trigger / Entry Point
Fill this after each paid external playtest wave.

## UX Flow
1. Export campaign, landing, TestFlight, telemetry, and survey data.
2. Fill the KPI snapshot.
3. Add the strongest clips and quotes.
4. State the top design risks and next build actions.

## Rules
- Lead with evidence, not adjectives.
- Separate creative interest, install behavior, and gameplay sentiment.
- Do not present paid-playtest enthusiasm as true long-term retention.

## Rewards / Economy Impact
- None.

## Risks
- Small samples are directional, not predictive.
- The current BOG demo is still narrower than the full product vision.

## Dependencies
- Meta reporting
- signup exports
- TestFlight metrics
- PlayFab telemetry
- survey results

## Open Questions
- Which external promise deserves the next spend wave
- Whether the next build should prioritize clarity, depth, or content breadth
